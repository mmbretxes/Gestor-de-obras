¿Cómo obtener tu ID de Cliente OAuth 2.0 gratuito en 2 minutos?
  1. Entra en Google Cloud Console, crea un proyecto y activa la Google Drive API en "Biblioteca".
  2. En "Pantalla de consentimiento de OAuth", selecciona tipo Externo, pon nombre a la app (ej. DocuObra) y añade tu correo como usuario de prueba.
  3. En "Credenciales" → "Crear credenciales" → "ID de cliente de OAuth", elige Aplicación web.
  4. En Orígenes de JavaScript autorizados, añade el origen desde donde abras este archivo (por ejemplo: https://mmbretxes.github.io o http://localhost:8080).
